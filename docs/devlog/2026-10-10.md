# Devlog — 2026-10-10

## 99. Wheel spray P1-P2: painterly mud and gravel spray

The owner asked for particles; wheel spray for mud and gravel first, in the ground's painterly style (docs/WHEEL_SPRAY_PLAN.md).

- P0: Niagara can be built headless. UE 5.8's experimental `UNiagaraExternalEditUtilities` creates systems from engine templates,
  adds User parameters, links and sets module inputs, sets renderer and emitter properties by JSON, and compiles. It is C++ only,
  so Python calls `UGTNiagaraSetupLibrary`. A link to a static switch crashed the editor, so every input write is now guarded by the
  emitter's topology (module, input name, type, visible and editable, never a switch for a link).
- P1: eight thrown clumps, three 1024 atlases (mud droplets, gravel grit, the dust puff's flipbook), headless Blender. P1b after the
  look: the clumps were faceted rocks; now smooth, droopy, torn, 276 triangles, at most 6 cm.
- P2: `NS_GT_WheelSpray` (MudDroplets and GravelGrit on the GPU with depth-buffer collision, GravelDust on the CPU), one per wheel,
  rates from the CPU spray's own kind and factors, in noise-driven bursts; the thrown mud blobs drawn as the clumps in the patch's
  slice; gravel wheels know they are on gravel (`bInGravelPatch`). `gt.Spray.Art 0` is the greybox exactly.
- Found on the way: a Niagara system built over an existing package in one editor session saved fine but crashed every later load
  (in -game first, where the spray test died in the asset load). The setup now removes the old file before the editor starts.
- Tests 17/17 (Spray.Art new), CRC 8e0aad06; the spray drive test passes at Art 1 and 0. Pictures and live counts per emitter in
  Art/Export/WheelSpray. The plan's gravel rates are sparse at full speed (10 grit, 2.5 dust a second a wheel); two extra pictures at
  FineScale 4. Owner: drive mud and gravel with the switches, `stat Niagara`.
