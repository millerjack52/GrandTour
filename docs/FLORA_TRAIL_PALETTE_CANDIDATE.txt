Reference inspection and findings
The five original images named in reference-evidence.json were opened, not
only the analysis boards. Green woodland remains the primary daylight target;
the path supplies selective lighting/depth and open conifers the warm/cool
relationship. Pink forest and blue-fog forest remain separate mood profiles.

Existing saved Unreal road, mixed-material and upward-crown views were also

Undergrowth is predominantly low dark clumps, with weak fern-fan readability

The previous camera labelled canopy aims strongly upward into the sky; it is
not adequate evidence for the depth gate. The new lower path camera and the
elevated valley camera are provisional until actual renders establish their
coverage. The old upward camera is retained as a crown diagnostic.

Source audit: causes to test, not visually confirmed diagnoses
1. Source34 tree/pine output a constant world +Z diffuse normal. At a fixed
   sun altitude, changing azimuth cannot give that normal new branch-facing
   response; only visibility/shadows change. Source pigment and coverage still
   vary, so this does not prove that normals alone explain the visual problem.
2. Existing undergrowth uses the older conversion in flora_exact_materials.py:
   weighted pigment is squared for transmission, divided by pi for direct
   light, and accompanied by an analytic ambient term. Its reflection direct
   contribution is gated off for an above-horizon source sun. Tree/pine now
   use the calibrated native diffuse response instead. Fern diffuse weight
   is about .766; shrub/grass about .295, with other shrub slots differing.
   This is a concrete family-response mismatch to investigate after tree
   diagnostics, not permission to relabel the remaining conversion as matched.
3. Standard display has prior midgrey evidence, but the new run will check
   it again in actual game output. One neutral card only establishes midgrey
   transfer; it cannot certify the entire highlight curve or exposure gamut.

Prepared controlled test
Art/flora_trail_palette_probe_settings.json defines cameras and cases.
Art/Unreal/probe_flora_trail_palette.py makes local copies of tree materials
and changes assignments only in PIE. The saved map and calibrated shaders
remain protected. The identity probe first holds pigment=(1,1,1) and normal
blend=0, so its output must retain the baseline before other cases are used.

Cases: saved daylight; identity probe; neutral sun/sky chromaticity at unchanged
energy; tree pigment multiplier alone; tree mesh-normal blend alone; reversed
sun azimuth at unchanged altitude; normal blend plus reversed azimuth. The
last case is an explicit interaction test, not a one-variable comparison
against baseline. The normal probe folds mesh normals into the upper
hemisphere and blends them with +Z; it is an art-direction experiment and
does not claim Blender source parity. No emissive foliage is introduced.

All cases restore the original settings before applying their one named group.
Exposure, Standard display, fog, FOV and render quality remain fixed. Source
coverage and texture bindings remain intact. The script checks 4K bark loading,
requests fully loaded used textures, waits before capture and records PNG IHDR
dimensions rather than equating requested window size with native resolution.
The fixed exported tree graphs must have no connected wind/WPO output.
