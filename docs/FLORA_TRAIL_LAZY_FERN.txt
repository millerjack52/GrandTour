FloraTrail: selected owned Lazy Forest fern
=========================================
15 November 2026. User resumed the Unreal trial; isolated candidate installed.

Selection
Use Lazy Forest Gen v2.0.5 Fern_02, following the user's choice to use the
owned option in the fern shortlist. This replaces the pending generated-atlas
experiment as the next candidate. No existing candidate files were deleted.

Verified source facts
Assets/Assets.blend contains seven fern objects. Fern_02 is a mesh with 1,683
vertices, 2,816 triangles, one UVMap and one Plant material, with no modifiers.
Its dimensions are approximately 0.771 x 0.718 x 0.424 metres. The material
uses texture_a01.png (4K colour and alpha) and texture_a01_mask1.jpg (4K).
The latter controls colour/translucency relationships; it is NOT the cutout
mask. Cutout coverage comes from the colour atlas alpha. The shader also has
colour mixes, RGB curves, object variation and a bump response from colour.
Do not treat a plain FBX import or generic solid green material as a transfer
of this appearance. Source appearance is not yet verified in Unreal.

Completed preparation
Art/Blender/export_lazy_fern.py appends only this object, audits the material
graph, preserves an isolated Blender source object with its authored material,
and exports an FBX with the pivot centred on the base. Original geometry and
UVs are retained. A Blender FBX roundtrip passed vertex/triangle counts, UV
layer names and physical dimensions. The purchased source file hash remained
unchanged. Blender 5.1.2 was used only for inspection/export, not rendering;
this is not a Blender-version lighting parity result.

Installed candidate
/Game/GrandTour/ArtTests/FloraTrail/LazyFern/L_FloraTrail_LazyFern
Launch separately with Drive-FloraTrail-LazyFern.bat. Existing launchers and
all previous maps remain unchanged; LiDAR is unchanged.

The authored colour chain (mixes, RGB curves, one frozen object variation),
coverage and transmission factor were baked to separate 4K atlases without
lighting. Tangent-space bump normals were baked on the original mesh, DirectX
convention. A full-atlas plane preserves colour/coverage through overlapping
source UVs. Original purchased files are untouched. These are data bakes,
not a Blender 3.4.1 lighting-parity claim for this different source pack.

Unreal uses native masked two-sided foliage, source coverage cutoff .35,
source-derived roughness .605263, specular .08, diffuse gain .45 and pigment
x transmission x .15 for subsurface colour. No emissive or grading change.
Normal/coverage/transmission maps are linear; colour is sRGB/BC7. All maps
must finish asynchronous loading at 4096 before captures. Three LODs use
100%, 65%, 35% triangle targets at screen sizes 1, .10, .035. LOD0 is 2,816
triangles. LOD transitions across the entire distance range are not certified.

All 159 fern instances retain their transforms. At native size this fern is
77 cm wide rather than the previous 141 cm, and about the same 42 cm height.
It therefore forms a narrower, more upright clump. There is no hidden scale
adjustment to make the before/after silhouettes artificially equivalent.

Review
The same paused scene and cameras capture previous/new fern, mixed bank and
road views at actual 1274 x 682. A/B swaps use runtime-only movable mobility
because Unreal refuses mesh swaps on static components during play. An
assertion now checks the actual displayed mesh. Fresh saved-map verification
retains the saved static mobility. A 48-frame camera move has eight captured
samples; this checks sampled shape/detail continuity, not sustained FPS or
complete temporal stability. The fern has no newly added wind animation.

Visual assessment of the candidate comparisons:
- Leaflet separation, veins, pale local highlights and dark inner fronds are
  substantially more readable than the previous broad, nearly flat green fern.
- The bank view retains visible fern detail. The road overview changes less;
  a fern replacement does not fix the other undergrowth or the tree palette.
- New ferns are cooler/paler than surrounding olive foliage. The contrast is
  useful, but palette integration remains partial. Do not call this reference
  matched. Other plants still show noisy cutout edges and uniform colour.
- Greyscale thumbnails show stronger fern volume, but the fine striped leaf
  pattern and surrounding vegetation compete at a distance.
- Sampled motion frames retain the fronds and their texture. Fine edge noise
  remains; no full temporal or 60 fps pass is claimed.
