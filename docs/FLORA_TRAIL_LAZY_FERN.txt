Selection

owned option in the fern shortlist. This replaces the pending generated-atlas
experiment as the next candidate. No existing candidate files were deleted.

Verified source facts
Assets/Assets.blend contains seven fern objects. Fern_02 is a mesh with 1,683
vertices, 2,816 triangles, one UVMap and one Plant material, with no modifiers.
Its dimensions are approximately 0.771 x 0.718 x 0.424 metres. The material
uses texture_a01.png (4K colour and alpha) and texture_a01_mask1.jpg (4K).
The latter controls colour/translucency relationships; it is NOT the cutout
mask. Cutout coverage comes from the colour atlas alpha. The shader also has
colour mixes, RGB curves, object variation and a bump response from colour.
Do not treat a plain FBX import or generic solid green material as a transfer
of this appearance. Source appearance is not yet verified in Unreal.

Completed preparation
Art/Blender/export_lazy_fern.py appends only this object, audits the material
graph, preserves an isolated Blender source object with its authored material,
and exports an FBX with the pivot centred on the base. Original geometry and
UVs are retained. A Blender FBX roundtrip passed vertex/triangle counts, UV
layer names and physical dimensions. The purchased source file hash remained
unchanged. Blender 5.1.2 was used only for inspection/export, not rendering;
this is not a Blender-version lighting parity result.
